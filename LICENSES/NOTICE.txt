and the C reference code in Tests/CGPIOReference, Tests/CTimeReference,
Tests/CRCCReference, Tests/CRCCControlReference, Tests/CRCCExtendedReference,
Tests/CRNGReference, Tests/CWatchdogReference, Tests/CDMAReference,

The Swift translations are modifications of the upstream C implementation.
The C GPIO driver and headers used by host tests are unmodified. Timebase
and RCC reference function bodies are extracted without modification;
their surrounding host register shims and test wrappers are new code.

The register layout corrections, atomic register helpers, and host CMSIS shim
use definitions from STMicroelectronics/cmsis-device-h7rs, revision
7e6e213ddc397c76622a0aca2f623ccc3b34c010, Include/stm32h7s3xx.h and
Include/stm32h7s7xx.h, and Include/stm32h7rsxx.h.
